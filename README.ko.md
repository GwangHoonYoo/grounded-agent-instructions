# Grounded Agent Instructions

[English](README.md) | [한국어](README.ko.md)

전제와 근거를 검토하고, 이해 수준에 맞춰 개입하며, 사용자의 언어로 답변하도록 하는 짧은 [AGENTS.md](AGENTS.md)입니다. 지속 지침·메모리·스킬은 영어로 작성하고, 특정 언어의 말투·뉘앙스에 필요한 표현은 원문으로 유지합니다.

Markdown 파일 하나를 에이전트가 읽는 지침에 복사하거나 통합해 사용합니다. 런타임·API 키·패키지 의존성이 없습니다.

## 에이전트에 적용하는 원칙

- **문제 정의를 검토합니다.** 판단을 바꿀 수 있는 근거·가정·누락된 고려사항을 확인합니다.
- **권한 범위 안에서 판단합니다.** 요청한 방법에 중요한 문제가 있으면 이유를 설명하고 실제 목표에 부합하는 대안을 제안합니다.
- **근거에 맞춰 행동을 조절합니다.** 불확실한 동안 수정 가능한 조사를 계속하고, 이해가 약해지면 영향이 큰 행동을 재검토합니다.
- **저장 언어와 대화 언어를 구분합니다.** 지속 지침은 영어로 작성하고, 답변은 사용자의 대화 언어와 명시적인 언어 요청을 따릅니다.
- **관련 맥락을 유지합니다.** 기억한 가정을 재검증하고, 허용된 저장 범위에서 목표·근거·미해결 쟁점·다음 확인을 유지합니다.

## 사용 방법

1. [AGENTS.md](AGENTS.md)를 열거나 저장소를 내려받습니다.

   ```sh
   git clone https://github.com/GwangHoonYoo/grounded-agent-instructions.git
   cd grounded-agent-instructions
   cat AGENTS.md
   ```

2. 적용 범위에 맞는 지침 파일에 내용을 통합합니다. 기존 프로젝트 규칙을 보존하고 충돌하는 지침을 조정합니다.

   | 에이전트 | 모든 프로젝트 | 특정 프로젝트 |
   | --- | --- | --- |
   | Codex | `~/.codex/AGENTS.md` | 프로젝트 최상위의 `AGENTS.md` |
   | Claude Code | `~/.claude/CLAUDE.md` | 프로젝트 최상위의 `CLAUDE.md` |
   | 기타 에이전트 | 해당 제품이 지정한 전역 지침 파일 | 해당 제품이 지정한 프로젝트 지침 파일 |

   Codex에 `$CODEX_HOME`이 설정돼 있으면 `~/.codex` 대신 해당 경로를 사용합니다. 같은 범위에 내용이 있는 `AGENTS.override.md`가 있으면 우선하며, 구체적인 프로젝트 지침이 전역 지침보다 우선할 수 있습니다. 실제로 읽는 파일에 통합해야 합니다. Claude Code에서는 **`AGENTS.md`의 본문**을 해당 `CLAUDE.md`에 통합합니다. 기존 `AGENTS.md` 지원은 클라이언트 설정과 버전에 따라 확인해야 합니다.

3. 새 세션에서 다음과 같이 확인합니다.

   > 현재 적용된 지침 중 전제 검토, 권한, 메모리 언어, 답변 언어에 관한 내용을 요약해 줘.

   이후 [평가 시나리오](docs/evaluation.md)를 적용합니다. 지침 요약은 읽기 여부를 확인하는 절차이며, 실제 행동은 별도로 평가해야 합니다.

설치 위치는 [Codex 공식 문서](https://learn.chatgpt.com/docs/agent-configuration/agents-md)와 [Claude Code 공식 문서](https://code.claude.com/docs/en/memory)를 기준으로 작성했습니다. 기타 클라이언트는 각 제품의 지침 적용 방식을 확인해야 합니다.

## 기대하는 행동 예시

설명을 위한 예시이며, 실제 모델 실행 결과는 아닙니다.

| 상황 | 기대하는 행동 |
| --- | --- |
| 계획이 전환율 40%라는 수치에 의존 | 지출 근거로 사용하기 전에 출처·분모·전환의 정의를 확인하고, 가능한 조사를 계속합니다. |
| 새 증거가 진행 중인 계획과 충돌 | 충돌하는 근거를 보존하고 가정을 수정하며, 조사하는 동안 영향이 큰 행동을 축소합니다. |
| 한국어로 선호를 기억해 달라고 요청 | 한국어로 답변하고 메모리는 영어로 작성합니다. 의미 보존에 필요한 한국어 표현만 유지합니다. |
| 스페인어로 영어 보고서를 요청 | 대화는 스페인어로, 보고서는 영어로 작성합니다. |
| 작고 명확하며 수정 가능한 변경 | 작업 규모에 맞춰 수행하고 불필요한 질문을 반복하지 않습니다. |

## 크기와 근거 범위

상시 지침에는 `AGENTS.md`만 포함하면 됩니다. README와 설계 문서는 선택적으로 참조합니다.

토큰 수와 측정 방법은 [설계 문서](docs/design.md#token-budget)에 기록합니다. 영어 저장은 이 프로젝트의 설계 선택이며, 절감 정도는 문장과 토크나이저에 따라 달라집니다. 이 템플릿의 성능 개선을 입증한 통제 실험은 없습니다. 지침은 행동을 유도하며, 강제 적용과 메모리 접근은 실행 환경에 따라 달라집니다.

## 연구 근거

선제적 개입 규칙은 Kirandeep Kaur, Xingda Lyu, Chirag Shah의 [*Position: Knowing Isn't Understanding: Re-grounding Generative Proactivity with Epistemic and Behavioral Insight*](https://arxiv.org/html/2602.15259v2), arXiv:2602.15259v2, 2026년 5월 31일 수정본에서 착안했습니다.

논문은 근거가 뒷받침하는 이해와 개입 강도를 함께 조절해야 한다고 제안합니다. 이 저장소는 일부 원칙을 실용적인 지침으로 작성한 것입니다. 영어 저장과 다국어 응답은 이 프로젝트가 추가한 설계 선택입니다. [원칙별 대응](docs/design.md#principle-mapping)을 확인할 수 있습니다.

## 기여 방법

재현 가능한 실패 사례를 제보하거나 범위가 명확한 변경을 제안할 수 있습니다. 클라이언트·모델, 관련 지침 범위, 익명화한 프롬프트, 관찰한 행동, 기대한 행동, 토큰 영향을 함께 기록합니다. 지속 지침은 영어로 작성하고 두 README를 함께 갱신합니다. [평가 절차](docs/evaluation.md)에 따라 설명용 예시와 실측 결과를 구분합니다.
